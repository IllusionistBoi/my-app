# Lessons

[2026-07-05] | Assumed the deployed SQLite database might contain user data that required a coordinated preservation cutover | Verify whether deployed data has real users or retention value before making data preservation a release blocker.
[2026-07-05] | Used `fileURLToPath(import.meta.url)` to locate a fixture inside a Vitest module, but Vite transformed it into a non-file URL | Resolve repository-level test fixtures from the test working directory when the runner bundles modules for a browser-like environment.
[2026-07-05] | Approved the redesign from limited viewport snapshots and missed cramped multi-word typography, excessive full-page whitespace, a gapped marquee, misaligned form panels, and reveal artwork covering results | Review complete desktop pages at multiple real widths plus focused, populated, and revealed states; keep negative display tracking conservative and reject any decoration that obscures content.
[2026-07-05] | Put the Rive asset provenance on the customer-facing hero even though it belongs in project documentation | Keep implementation history and recovered-asset notes in `PROJECT.md`; product UI copy must explain user value only.
[2026-07-05] | Integrated the teddy's form-state inputs without making its interaction model visible or testing pointer response | Define, implement, and browser-test every mascot trigger; a prominent interactive character should visibly track pointer movement in addition to form state unless reduced motion is requested.
[2026-07-05] | Overrode the repository's configured Vitest thread pool during verification and the stateful Rive stub run stalled | Use the checked-in test configuration for the full suite; change worker pools only for a focused diagnosis and return to the configured pool afterward.
[2026-07-06] | Assumed the backend verification shell would use development defaults, but it inherited `DJANGO_DEBUG=false` without a signing key | Set the complete Django test or deployment environment explicitly in every verification command; never rely on ambient shell variables.
[2026-07-06] | Let a full workflow test share a 30-second timeout with remote-backed setup and cleanup, so timeout could strand its disposable room | Wrap externally persisted E2E fixtures in `try/finally` cleanup and give the complete workflow a realistic explicit timeout.
[2026-07-06] | Animated the keyboard-only skip-link entrance and asserted its position before the transition settled | Keyboard focus feedback must be immediate; do not animate skip-link visibility.
[2026-07-06] | Supplied the removed repository-root virtual-environment path to the final E2E run even though the active environment lives under `backend/` | Resolve and verify the interpreter path from the current checkout before launching an end-to-end test server.
[2026-07-06] | Restored real timers before unmounting a component that owned a fake-timer interval, leaving Vitest with inconsistent timer cleanup | Unmount timer-owning test fixtures before restoring the real clock, and allow timestamp pollers one scheduling tick beyond exact boundaries.
[2026-07-06] | Kept a keyboard-focus assertion that assumed the page skip-link was first even after adding an accessible intro skip control | When a temporary overlay introduces an earlier focus target, test that control first, dismiss the overlay, then verify the underlying page focus order.
